# Tài liệu dự án

1. Đọc [CEFR spec](cefr-learning-planner-spec/00_README.md) làm nguồn chính về sản phẩm và kỹ thuật.
2. Đọc [bản tổng hợp CEFR + Bootcamp](cefr-learning-planner-spec/18_BOOTCAMP_CURRICULUM_INTEGRATION.md) để hiểu cách dùng lịch 120 ngày và học liệu bổ sung.
3. Dùng [MASTER_SPEC](cefr-learning-planner-spec/MASTER_SPEC.md) khi cần toàn bộ spec trong một file. Các file module riêng là nguồn duy trì; MASTER_SPEC là bản ghép theo thứ tự 00–18 rồi AGENT_IMPLEMENTATION_BRIEF.
4. Tra [roadmap bootcamp từng ngày](c1-bootcamp-120-day/02_120_Day_Roadmap.md) và các học liệu liên quan theo bảng nguồn của module 18.

Các tài liệu bootcamp gốc được giữ để đối chiếu. Khi có khác biệt, áp dụng CEFR spec và quy tắc tích hợp module 18; không lấy đề xuất kỹ thuật cũ hoặc lịch cứng làm yêu cầu ghi đè.
