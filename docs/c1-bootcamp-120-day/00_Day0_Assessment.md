# Day 0 — Placement & Baseline

Do this once before Day 1. Total: ~4 hours. Do **not** prepare for it.

## 1. External CEFR placement — 30–45 min

Use the British Council LearnEnglish level test / “Understand your English level” area. Record the reported level.

Write:

- Estimated CEFR: ____
- Grammar score: ____
- Vocabulary score: ____
- Notes: ____

## 2. Listening baseline — 30 min

Choose one A1 listening item from British Council. If ≥85%, move to A2; keep moving up until your score falls below 70%.

Record:

| Level | Score | Comfortable? |
|---|---:|---|
| A1 | | |
| A2 | | |
| B1 | | |
| B2 | | |
| C1 | | |

Your working listening level = highest level with **≥70% without transcript**.

## 3. Reading baseline — 30 min

Repeat the same ladder using British Council reading.

Your working reading level = highest level with **≥70% within a reasonable time**.

## 4. Speaking baseline — 20 min

Record yourself. No script, no dictionary.

### Task A — 2 minutes
Introduce yourself: background, current work/study, hobbies and one goal.

### Task B — 3 minutes
“Is artificial intelligence more helpful or more dangerous for ordinary workers?”

Save the audio. Do **not delete it**. You will compare it on Days 28, 56, 84 and 120.

## 5. Writing baseline — 30 min

Write 180–220 words, without translator:

**Topic:** “Why I want to improve my English and how it could change my future.”

Save the original version. Then ask ChatGPT to mark:

- grammar errors
- unnatural wording
- vocabulary level
- organization
- estimated CEFR
- top 5 recurring weaknesses

Do not rewrite until the original is saved.

## 6. Pronunciation baseline — 20 min

Read this aloud and record it:

> Learning a language is not only about memorising words and grammar. A strong learner must understand real speech, react quickly, explain ideas clearly and keep communicating even when the exact word is missing. My goal is to build that ability through consistent daily practice.

Check 10 difficult words in Cambridge Dictionary and YouGlish.

## Starting-level rule

- If Day 0 says **Pre-A1/A1**: start Day 1 normally.
- If solid **A2**: compress Days 1–21 into 10–14 days.
- If solid **B1**: jump to Day 36 after completing the Week 1 pronunciation/output routine.
- If already **B2**: use Days 85–120 as the core and spend the saved time on C1 mocks and feedback.
