## Mastery test for each item

You must be able to:

1. Explain the meaning in simple English.
2. Recognise it in real audio/text.
3. Produce five original examples.
4. Contrast it with the nearest competing structure.
5. Use it spontaneously in a 2-minute speaking task.
6. Use it accurately in a timed paragraph.
