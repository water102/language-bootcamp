# EXERCISE GENERATION

## 1. Principle

Question bank should be largely generated from legally reusable source facts, not manually stored as millions of independent questions.

## 2. Vocabulary templates

1. definition -> word MCQ
2. word -> definition MCQ
3. synonym selection
4. semantic related-word selection
5. POS identification
6. contextual cloze
7. spelling reconstruction
8. EN -> VI recall
9. VI -> EN production
10. word-family/derivation when data supports it

Distractors should match POS and roughly match CEFR; avoid a distractor that is also semantically correct.

## 3. Sentence templates

1. single-word cloze
2. multiword cloze
3. word order reconstruction
4. translation EN->VI
5. translation VI->EN
6. punctuation/capitalization repair
7. target-word highlighting
8. sentence/audio dictation
9. shadowing
10. read-aloud

## 4. Listening templates

Requires reusable audio or embedded media.
- full dictation;
- partial dictation;
- choose matching transcript;
- missing word;
- sequence/order;
- short comprehension;
- shadowing + self-rating;
- retell.

For YouTube/external media, questions belong to the app, media remains provider-hosted.

## 5. Reading templates

- main idea;
- factual detail;
- vocabulary in context;
- reference resolution;
- heading match;
- paragraph order;
- short summary;
- retell;
- true/false/not-stated when answer can be unambiguously derived.

AI may draft higher-order comprehension questions, but must provide evidence span and answer; validator rejects missing/ambiguous evidence.

## 6. Grammar templates

CEFR-J grammar profile supplies target structure metadata.
- identify structure;
- controlled cloze;
- choose correct form;
- sentence transformation;
- error correction;
- contrast two structures;
- mini production.

## 7. Validation rules

Auto-generated MCQ must satisfy:
- exactly one intended answer;
- distractors same grammatical category where applicable;
- answer appears/derives from source;
- no duplicate normalized options;
- no option-length giveaway when avoidable;
- CEFR mismatch threshold respected.

## 8. Difficulty adaptation

Same source item can generate levels of exercise difficulty:

```text
recognition -> controlled recall -> free recall -> production
```

Example vocabulary:
- easy: choose translation;
- medium: choose definition in context;
- hard: fill blank without options;
- mastery: produce own sentence.

## 9. XP integration

Reward task completion/assessment quality, not consumption of third-party media itself.
